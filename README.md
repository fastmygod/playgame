# 剑心问道

一个原创的仙侠风格横屏回合制 RPG，单个 HTML 文件，手机浏览器打开即玩。

- 立绘、战斗角色与妖怪、标题画面、战斗背景和结局插画为 AI 绘制的插画（`art/` 目录）
- 地图场景、地图小人和特效由 Canvas 程序绘制（飞檐青瓦的房屋、石板路、荷塘凉亭、竹林、火把照明的洞窟）
- 原创五声音阶配乐：古筝拨弦（Karplus-Strong 合成）+ 竹笛 + 太鼓 + 锣，带混响，6 首曲子各有曲谱
- 经典格子移动：十字方向键一格一格走，同伴跟随在身后
- 三张地图：青石镇 → 紫竹林 → 幽冥洞，含剧情、同伴入队、宝箱、商店、客栈
- 回合制战斗：攻击 / 仙术 / 物品 / 防御 / 逃跑，中毒状态，可开启自动战斗与二倍速
- 支线任务：帮王阿婆找回长命玉坠；可调查石碑、土地庙等
- 升级习得新仙术：御剑术、万剑诀、天雷破、回春术、冰心诀、烈焰咒、甘霖普降
- 进度自动保存（走动中每隔几秒、切换地图、战斗结束、切到后台时都会存档）

## 怎么玩

用浏览器打开 `index.html`（手机请横屏）。

| 操作 | 手机 | 键盘 |
| --- | --- | --- |
| 移动 | 左半屏拖动（推远可跑步） | 方向键 / WASD（Shift 跑步） |
| 交谈、开宝箱、调查 | 点右半屏或「察」 | 空格 / 回车 |
| 菜单 | 「菜单」按钮 | M / Esc |
| GM 测试面板 | 标题页右下「GM」或 菜单 → 系统 | ` 或 G |

## 文件

- `index.html`：可直接打开的完整页面
- `game.html`：游戏本体（不含 `<html>` 外壳），`index.html` 由它包一层文档头生成
- `art/`：插画资源（webp），加载失败时游戏会回退到程序绘制的立绘与背景

> 需要通过本地服务器或网页托管打开 `index.html`，插画才能正常加载（直接双击打开在部分浏览器中也可用）。
